## Building with purpose

I'm **Avanthika**, a Full-Stack Developer based in Kochi, India. I build web applications with **TypeScript, Next.js, Node.js, and Express**, connecting thoughtful interfaces with the APIs and data behind them.

My work spans business applications, admin dashboards, API integration, and production fixes. I enjoy turning complex requirements into clear workflows and maintainable code, with a growing focus on backend engineering.

- **Working on:** lead management, bulk import workflows, and configurable CRM experiences.
- **Interested in:** API design, relational databases, real-time systems, and cloud deployment.
- **My approach:** understand the problem, build carefully, and keep improving the details.
